# Projeto de Testes — Recuperação de Senha de Usuário
Nesse porjeto reqalizei teste de e-mail valido/inesistente, tambem realizei busca de campos vazios onde verifiquei se nao havia nada preenchido se ele iria retornar mesnagem de erro. link expirado, tambem realizei teste de redefinir senha de usuario. Tambem verifiquei mensagens de erro


# Objetivos 
- E-mail valido
- E-mail invalido
- Link expirado
- Redefinição de senha 
- Campos vazios
- Mensagem de erro

# Tecnicas Utilizadas 

- Testes funcionais 
- Caso de testes 
- Relatoris de bugs
- Evidencias

# Ferramentas

- Github
- Vs code
- Chrome

# Conculusao

Neste projeto de QA foram executados testes funcionais no fluxo de recuperação de senha, validando cenários positivos e negativos. As verificações incluíram validação de e-mails válidos e inválidos, envio de link de recuperação para o usuário, testes de campos obrigatórios vazios e análise do comportamento do sistema diante de entradas incorretas ou ausentes. O objetivo foi garantir a estabilidade, usabilidade e confiabilidade do processo de recuperação de conta.
